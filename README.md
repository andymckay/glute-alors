## About

This project is designed to help me with my running and interaction with a coach. We have a system for doing this, but it's currently based in the US and that means that some company in the US is getting my money and the US government is getting all the data about when and where I am almost every day. Since every peice of data or company use in the US is currently used as leverage to attack that country, I can't keep sending my data there.

Overall goal:
* Allow my coach to plan my runs out on a calendar for a few weeks, with some stats about what is planned.
* Automate updates from my watch after a run and compare that clearly to the plan.
* Allow manual updates from me about the run so that the coach can see them.
* Display information needed for my coach about the run.
* Provide simple notifications to me and coach about messages to each other regarding runs.
* Allow to host on a simple server somewhere not in the US.

That's about it.

## Naming

The name is a pun on the French exclamation `zut alors` and the <a href="https://en.wikipedia.org/wiki/Gluteal_muscles">Glute</a>, which is one of the most important muscles for running.
